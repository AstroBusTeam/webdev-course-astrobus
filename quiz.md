# Cuestionario final: pon a prueba tus conocimientos

Preguntas para crear el formulario (por ejemplo, con Google Forms en modo cuestionario). La respuesta correcta está marcada con ✅.

**1. ¿Qué se encarga de poner el contenido y la estructura de una página web?**
- ✅ HTML
- CSS
- El navegador
- La imagen de fondo

**2. ¿Qué hace el CSS?**
- Escribe los textos de la página
- ✅ Da estilo: colores, fuentes y orden
- Guarda las imágenes
- Cierra las etiquetas

**3. ¿Cómo se llama la parte `lang="es"` de la etiqueta `<html lang="es">`?**
- Elemento
- ✅ Atributo
- Selector
- Comentario

**4. ¿Qué etiqueta crea el encabezado más importante de la página?**
- `<p>`
- `<h6>`
- ✅ `<h1>`
- `<head>`

**5. ¿Para qué sirve el atributo `alt` de una imagen?**
- Para cambiar su tamaño
- ✅ Para describir la imagen con palabras
- Para ponerle un borde
- Para moverla de lugar

**6. ¿Qué etiqueta se usa para crear una lista numerada?**
- `<ul>`
- ✅ `<ol>`
- `<li>`
- `<a>`

**7. ¿Cuál es la forma correcta de una regla CSS?**
- `h1 (color = red)`
- `h1: color { red }`
- ✅ `h1 { color: red; }`
- `<h1 color="red">`

**8. ¿Qué propiedad CSS sirve para redondear las esquinas de una caja o imagen?**
- `text-align`
- ✅ `border-radius`
- `font-family`
- `background-color`

**9. En CSS, ¿cómo se escribe el selector de una clase llamada `tarjeta`?**
- `tarjeta`
- `#tarjeta`
- ✅ `.tarjeta`
- `<tarjeta>`

**10. Tu página no muestra el color que escribiste en el CSS. ¿Qué es lo primero que deberías revisar?**
- ✅ Que la propiedad esté bien escrita y la línea termine con punto y coma
- Que el navegador sea nuevo
- Que la imagen sea grande
- Que el título sea corto
