# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 1 hora introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas!** Solo abre tu navegador web.

**Duración total**: ~60 minutos
**Público objetivo**: Estudiantes de 12 a 17 años sin experiencia en programación
**Prerrequisitos**: Ninguno
**Herramientas necesarias**: **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)

**📂 Repositorio de código fuente**: [https://github.com/AstroBusTeam/webdev-course-astrobus](https://github.com/AstroBusTeam/webdev-course-astrobus)

**Al terminar el curso, podrás**:
- Explicar qué es un sitio web y de qué está hecho.
- Escribir la estructura básica de una página en HTML.
- Usar encabezados, párrafos, listas, imágenes y enlaces.
- Darle color, fuente y orden a tu página con CSS.
- Publicar tu propia página de perfil personal.

## Secuencia de la lección

### Lección 1: ¿Qué es el desarrollo web? (3:46 minutos)

- **Descripción**: Descubre de qué están hechos los sitios web y por qué HTML y CSS son sus componentes básicos.
- **Enlace**: [Ver la lección]()
- **Consejos clave**: Sitio web = Contenido (HTML) + Estilo (CSS).
- **Empieza a explorar**: [https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a156b4-9e2b-7ba2-a119-10b6320f928a](https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a156b4-9e2b-7ba2-a119-10b6320f928a)

### Lección 2: Introducción a HTML (8:01 minutos)

- **Descripción**: Conoce las etiquetas, los elementos y los atributos, y crea tu primera página.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=ENLACE-2)
- **Consejos clave**: Usa `<html>`, `<head>`, `<body>`, `<h1>` y `<p>`. Toda etiqueta que se abre, se cierra.
- **Práctica**: [https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15a00-3cf8-7c15-bcca-3797c36d8af3](https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15a00-3cf8-7c15-bcca-3797c36d8af3) 👈 **¡No necesitas registrarte!**

### Lección 3: Añadir más elementos HTML (8 minutos)

- **Descripción**: Agrega listas, imágenes y enlaces para que tu página sea más completa.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=ENLACE-3)
- **Consejos clave**: Usa `<ul>`, `<li>`, `<img src="" alt="">` y `<a href="">`. Siempre escribe el texto alternativo (`alt`).
- **Práctica**: [https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b45-d0c5-7ae5-bdbb-211550fa814a](https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b45-d0c5-7ae5-bdbb-211550fa814a) 👈 **¡Comienza al instante!**

### Lección 4: Introducción a CSS (12 minutos)

- **Descripción**: Dale estilo a tu HTML con colores, fuentes, bordes y centrado de contenido.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=ENLACE-4)
- **Consejos clave**: Un selector + propiedades, por ejemplo `body { background-color: lightblue; }`. Practica con `color`, `font-family`, `border` y `text-align`.
- **Práctica**: [https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b47-1067-764b-acc4-b6718aa70744](https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b47-1067-764b-acc4-b6718aa70744) 👈 **¡No es necesario registrarse!**

### Lección 5: Crear una página web sencilla (15 minutos)

- **Descripción**: Combina HTML y CSS para crear tu página de perfil personal paso a paso.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=ENLACE-5)
- **Consejos clave**: Planifica primero la estructura, aplica estilos por partes y prueba cada cambio.
- **Proyecto final**: [https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b48-85e4-7b6f-9807-34f24539b736](https://codepen.io/editor/Andy-Pillaca-Gonzales/pen/01a15b48-85e4-7b6f-9807-34f24539b736) 👈 **¡Guarda y comparte!**

### Lección 6: Consejos y próximos pasos (10 minutos)

- **Descripción**: Errores comunes, buenas prácticas y dónde seguir aprendiendo.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=ENLACE-6)
- **Consejos clave**: Revisa que las etiquetas estén cerradas, usa nombres claros y consulta la documentación web de MDN.
- **Comparte tu trabajo**: [Envía tu creación](https://forms.gle/ENLACE-FORM)
