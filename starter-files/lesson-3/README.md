# Lección 3 · Añadir más elementos HTML

**Archivo**: `index.html` (parte de la página de la lección 2)

## 🎯 Ejercicio guiado (durante el video)
1. Agrega un `h2` que diga "Mis cosas favoritas".
2. Crea una lista con `ul` y tres elementos `li`.
3. Agrega una imagen con `img`, con su atributo `src` y su texto `alt`.
4. Agrega un enlace con `a` y el atributo `href`.

## 💡 Pistas
- La etiqueta `img` no lleva etiqueta de cierre.
- El texto `alt` describe la imagen con palabras: ¿qué se ve en ella?
- Puedes usar `https://placehold.co/300x200` como imagen de ejemplo.

## 🚀 Reto extra: mi receta favorita
Crea una página con:
- un `h1` con el nombre de la receta y una imagen,
- un `h2` "Ingredientes" con una lista con viñetas (`ul`),
- un `h2` "Pasos" con una lista **numerada** (`ol`),
- un enlace a un video o una página sobre la receta.

**Pregunta para pensar**: ¿qué diferencia hay entre `ul` y `ol`?
