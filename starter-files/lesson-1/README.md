# Lección 1 · ¿Qué es el desarrollo web?

**Archivos**: `index.html`, `style.css`

## 🎯 Ejercicio guiado (durante el video)
1. Abre el editor en línea con el código de esta lección.
2. Busca en el CSS la propiedad `background-color`.
3. Cambia `white` por otro color, por ejemplo `lightyellow` o `lightpink`.
4. Mira cómo cambia la página **sin tocar el HTML**.

## 💡 Pistas
- Puedes usar nombres de colores en inglés (`red`, `skyblue`, `orange`) o códigos como `#ffcc00`.
- Si no cambia nada, revisa que la línea termine con punto y coma `;`.

## 🚀 Reto extra
Cambia el texto del título `h1` por tu nombre y agrega una regla CSS para que ese título tenga un color distinto al del resto de la página.
