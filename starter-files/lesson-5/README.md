# Lección 5 · Crear una página web sencilla

**Archivos**: `index.html`, `style.css`

## 🎯 Ejercicio guiado (durante el video)
Construye tu página de perfil siguiendo los comentarios del archivo `index.html`:
1. Tu nombre con `h1`.
2. Una imagen con `img` (con `alt`).
3. Un párrafo sobre ti.
4. Una lista de tus pasatiempos.
5. Un enlace a tu sitio favorito.

Después, en `style.css`:
6. Agrupa todo dentro de un `div` con la clase `tarjeta`.
7. Dale a `.tarjeta` fondo, borde, esquinas redondeadas y un ancho máximo.
8. Centra la tarjeta con `margin: 0 auto;`.

## 💡 Pistas
- En CSS, una clase se escribe con un punto: `.tarjeta { ... }`.
- En HTML, se usa el atributo `class="tarjeta"`.
- Prueba tu página después de cada paso, no al final.

## 🚀 Reto extra: agrega una segunda tarjeta
1. Crea otra tarjeta con el título "Mis metas" y una lista de 3 metas.
2. Reutiliza la clase `tarjeta` para que se vea igual que la primera.
3. Agrega una sombra a las tarjetas con `box-shadow: 0 4px 8px rgba(0, 0, 0, 0.2);`.
4. Separa las tarjetas con `margin-bottom`.
