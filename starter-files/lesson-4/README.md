# Lección 4 · Introducción a CSS

**Archivos**: `index.html`, `style.css` (el HTML ya está vinculado al CSS)

## 🎯 Ejercicio guiado (durante el video)
1. Cambia el color de fondo del `body`.
2. Cambia el color del título `h1`.
3. Elige una fuente con `font-family` y centra el texto con `text-align`.
4. Ponle un borde a la imagen con `border` y esquinas redondeadas con `border-radius`.

## 💡 Pistas
- Una regla CSS siempre tiene esta forma: `selector { propiedad: valor; }`.
- Para un borde necesitas tres cosas: grosor, tipo de línea y color, por ejemplo `3px solid red`.
- Si un estilo no se aplica, revisa el punto y coma y las llaves.

## 🚀 Reto extra: estilo para la receta
Toma la página de la receta del reto de la lección 3 y dale estilo:
- un color de fondo suave y una fuente a toda la página,
- los `h2` de un color distinto y con una línea debajo (`border-bottom`),
- los elementos de las listas (`li`) de otro color,
- la imagen con esquinas redondeadas.
