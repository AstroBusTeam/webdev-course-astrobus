# Lección 2 · Introducción a HTML

**Archivo**: `index.html`

## 🎯 Ejercicio guiado (durante el video)
1. Dentro del `body`, escribe un título con `h1` que diga tu nombre.
2. Debajo, escribe un párrafo con `p` que cuente algo sobre ti.
3. Cambia el `title` de la página (el texto que aparece en la pestaña): reemplaza "Título de la página" por "Mi primera página".

## 💡 Pistas
- Toda etiqueta que abres, debes cerrarla: `<h1>` ... `</h1>`.
- El texto va **entre** la etiqueta de apertura y la de cierre.

## 🚀 Reto extra: ficha de tu animal favorito
Crea una ficha con:
- un `h1` con el nombre del animal,
- un párrafo que lo describa,
- un `h2` que diga "Dato curioso",
- otro párrafo con ese dato.

**Bonus**: usa `<strong>` para resaltar una palabra importante y `<em>` para darle énfasis a otra.
