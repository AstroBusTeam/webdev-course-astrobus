# Solución · Lección 3

## Ejercicio guiado
Ver `index.html`: contiene `h2`, `ul` con tres `li`, una `img` con `src` y `alt`, y un enlace `a` con `href`.

## Reto extra
Ver `reto-extra.html`. Diferencia clave:
- `ul` (*unordered list*) crea una lista **con viñetas**, cuando el orden no importa.
- `ol` (*ordered list*) crea una lista **numerada**, cuando el orden sí importa (como los pasos de una receta).

## Errores frecuentes
- Poner un `li` fuera de un `ul` o un `ol`.
- Olvidar el atributo `alt` de la imagen.
- Escribir el enlace sin `https://` al principio de la dirección.
