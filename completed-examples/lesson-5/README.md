# Solución · Lección 5

## Ejercicio guiado
Ver `index.html` y `style.css`: la página de perfil dentro de una tarjeta centrada.

## Reto extra
Ver `reto-extra.html`. Idea clave: una **clase** se puede **reutilizar** en varios elementos. Las dos tarjetas usan `class="tarjeta"`, así que comparten el mismo estilo sin repetir el código CSS.

## Errores frecuentes
- Escribir `.tarjeta` en el HTML (con punto): en el HTML se escribe `class="tarjeta"`.
- Olvidar cerrar el `div`.
- Centrar con `margin: 0 auto` sin definir un `max-width` o un `width`: no se nota el efecto.
