# Solución · Lección 2

## Ejercicio guiado
Ver `index.html`: un `h1` con el título, un `p` con el texto y un `title` nuevo dentro del `head`.

## Reto extra
Ver `reto-extra.html`: una ficha con `h1`, `p`, `h2` y otro `p`. Las etiquetas `strong` (negrita, importancia) y `em` (cursiva, énfasis) se escriben dentro del texto del párrafo.

## Errores frecuentes
- Etiquetas sin cerrar.
- Escribir contenido fuera del `body`: no se verá en la página.
- Mezclar el orden de cierre: `<p><strong>texto</p></strong>` está mal; lo correcto es `<p><strong>texto</strong></p>`.
