# Solución · Lección 4

## Ejercicio guiado
Ver `style.css`: reglas para `body` (fondo, fuente y centrado), `h1`, `img` y `a`. Son exactamente las que se escriben en el video.

## Reto extra
Ver `reto-extra.html` (HTML y CSS juntos en un solo archivo). Para pegarlo en un editor en línea con paneles separados, copia el contenido de `<style>` en el panel CSS y el contenido de `<body>` en el panel HTML.

## Errores frecuentes
- Usar `:` y `;` al revés o escribir `=` en lugar de `:`.
- Escribir el selector de una clase sin el punto.
- Olvidar la unidad: `font-size: 18` no funciona; debe ser `18px`.
