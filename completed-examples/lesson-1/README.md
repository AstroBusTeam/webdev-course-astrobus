# Solución · Lección 1

## Qué cambia entre `starter-files` y `completed-examples`
Solo una línea del CSS:

| Archivo | Starter | Completed |
|---|---|---|
| `style.css` | `background-color: white;` | `background-color: lightyellow;` |

El HTML no cambia: eso demuestra que el contenido y el estilo están separados.

## Reto extra
Ver `reto-extra.html`. Se cambió el texto del `h1` y se agregó una regla `h1 { color: tomato; }`. Un selector `h1` solo afecta a los títulos, no a los demás elementos.

## Errores frecuentes
- Olvidar el punto y coma al final de la línea.
- Escribir el color sin el `#` cuando es un código (`ffcc00` en lugar de `#ffcc00`).
